# 小满 · 成长证据库 使用说明书

> 小满者，小得盈满——将满未满，日进一步。

一款跑在自己电脑上的个人成长记录器：像写日记一样记录每天的工作和生活，
AI 帮你做周报/月报、提炼经验、画成长路线，为将来写书和培训新人积累素材。

**所有数据都在你自己电脑的 `data` 文件夹里，不经过任何别人的服务器。**

---

## 一、怎么启动

1. 电脑上需要装一次 Python（3.11 以上）：到 <https://www.python.org/downloads/> 下载，
   **安装时务必勾选 "Add python.exe to PATH"**。装过就跳过这步。
2. 双击 `start.bat`。
   - 第一次运行会自动准备环境（约 1-2 分钟，以后秒开）。
   - 如果 Windows 弹出"防火墙"提示，**请勾选"专用网络"并点允许**，否则手机连不上。
3. 浏览器会自动打开 <http://localhost:52122>，就可以开始记录了。
4. **关闭那个黑色命令行窗口 = 停止程序。** 电脑关机后手机端也会打不开，这很正常。

## 二、手机怎么用（拍照片视频最方便）

1. 手机和电脑连**同一个 Wi-Fi**，电脑上双击启动 `start.bat`。
2. 打开电脑网页的 `设置` 页，顶部「手机连接」卡片里有**二维码**和地址，
   手机扫码（或浏览器输入那个地址）就能打开。可以把网页"添加到主屏幕"，用起来就像 App。
3. 点"拍照"可以直接调用相机；连在 Wi-Fi 上时，照片视频立刻存到电脑，**不占用手机空间**。
4. **在外面没连电脑也能记**：页面开着的时候断网了照样写，记录（包括拍的照片、文件）
   会先保存在手机本地，今天页会显示"N 条待同步"；回到家连上 Wi-Fi 会自动同步到电脑，
   也可以点那条提示手动同步。
   注意一个限制：如果网页整个被关掉了，断网状态是打不开的（浏览器安全规定），
   需要重新连上电脑的 Wi-Fi 才能打开。所以出门前可以保持标签页不关。

## 三、记录（今天页）

- 打开就是"今天"页：一个大输入框，想到什么写什么。**标题、摘要、标签都可以不写**，
  正文、照片、链接有任意一样就能保存（Ctrl+Enter 快捷保存）。
- **工作日志模板**：快速记录框和详情页正文上方有一排小按钮：工作内容、挑战、
  解决办法、提升、手记、见识、学习。点一下就在正文里插入一个对应的小节标题，
  接着往里写就行——它们就是普通文本，随便改、随便删。
  **模板可以自己定**：设置页的"日志模板"卡片里可以删掉用不上的、加上自己的
  （比如"会议纪要""巡检记录"，最多 12 个）。
- **补写以前的日志**：快速记录卡上有个日期时间选择器，默认是现在；
  改成过去的某天再写，就是补记（补记的内容出现在日历和记录页对应的日子）。
- **拍照识别手写笔记**：点媒体按钮里的"拍照识别"，拍下纸质笔记（**可多选，一次最多 9 页**；
  手机上选"相册"就能多选几页一起传）。AI 会把多页内容按顺序合并成一条记录，
  提取日期、天气、正文（认不出的字用 □ 标，不瞎编），手画的图、表格会按区域裁成附图，
  生成后打开让你检查修改。需要模型支持视觉；识别失败时按提示去设置页调整。
- **附件网页内预览**：点击附件直接预览——文本（txt/md/json/csv 等）、PDF、音频、
  图片、视频都在页面里打开，不再跳新标签；其他格式提供下载。
- **草稿不怕丢**：今天页写了一半切走，回来会自动恢复未保存的内容。
- **一天可以写很多篇**：工作日志、生活记录互不影响，"今天"页按时间排列。
- 可以附加：照片、视频、任意文件、网页链接（链接会自动抓取标题）。
- 记录不用纠结分类：只有「工作」一颗小开关（默认交给小满判断）；
  AI 会在后台自动给每条记录打上 1–3 个类目（工作事务、现场与农事、问题解决、学习成长、
  人际协作、想法灵感、心情感受、身体与健康、生活日常、亲友时光、兴趣娱乐、钱与物），
  你手动标过"工作"的记录永远以你为准。
- 开启"自动获取天气和位置"（设置页可关）后，保存时会**自动带上当时的地点、天气和温度**；
  电脑端没开定位时会用"设置"里填的默认城市。没联网就不填，不影响保存。
  **关闭该开关后**：不再获取天气和定位，新记录的地点只预填为"公司"。
- **这些只是预填，填错了随时能改**：点进那条记录，地点、天气、温度都在"更多细节"里，
  可以直接编辑，也可以点"重新获取"按当时的时间地点再预填一次，确认后保存。
- 写错了随时改：`记录`页找到它，点进去编辑。删除的记录进回收站（设置页可恢复），
  30 天后才会真正清除。

## 四、AI 功能（需要你自己填 AI 接口）

打开 `设置` 页，可以配置 AI 供应商。现在可以同时保存多家服务商，并分别为大模型、小模型、嵌入模型选择当前使用的一家；每家都支持编辑、删除、启用和测试连接。

页面仍保留三个模型用途槽位：

- **大模型**：负责识图（拍照识别）、日报/周报/月报、成长轨迹、知识提取等重活。
- **小模型（可选）**：负责自动标题、摘要、分类等轻活，推荐填便宜快速的型号；
  留空则与大模型共用。三个用途可以分别使用不同供应商、不同 Key。
- **嵌入模型（可选）**：负责语义搜索——配上之后"问小满"和"相关的回忆"就能理解语义，
  不再只靠关键词。Base URL 和 Key 留空则与大模型共用，填模型名即可
  （如 `text-embedding-3-small`、通义 `text-embedding-v3`）。

新增供应商时填写名称、用途、**Base URL**（如 DeepSeek `https://api.deepseek.com/v1`、
通义千问 `https://dashscope.aliyuncs.com/compatible-mode/v1`、OpenAI `https://api.openai.com/v1`）、
**模型名**（如 `deepseek-chat`、`qwen-plus`、`gpt-4o-mini`）、**Key**（形如 `sk-...`）。
填完可先测试再保存；编辑时 Key 留空会沿用已保存的 Key，并测试你刚改的地址和模型。**Key 只存在你自己电脑上，接口响应不会回传明文。**

原有旧版配置会在升级时自动导入为“当前大模型 / 当前小模型 / 当前嵌入模型”，不会丢失。切换嵌入模型后，语义索引会自动清空并在后台重建。

有了 AI 之后：

- **自动减负**：保存记录后，小模型会在后台自动补上缺的标题、摘要和标签，
  并自动归类（12 个类目打 1–3 个，拿不准的类目宁可不打；你没点"工作"开关时它也会判断）。
  **编辑正文后也会自动重补空缺的字段**，历史记录会在后台悄悄理顺（首次升级后会自动重判一轮分类）。
  详情页有"AI 补全"按钮，设置页能一键给历史记录批量补标题。
  标记了"不让 AI 分析"的记录：不补全、不向量化、不进报告，内容绝不出本机。
- **可能相关**：保存后小满会在后台比对——这条记录和你的工作、事件线索、成长方向
  有没有隐性关联（比如周末练车 ↔ 工作里的观光车任务）。有的话，详情页底部会出现
  低调的"可能相关"小折叠区，附一句"为什么相关"；你确认过的关联会在写周报时供参考。
- **报告页**：一键生成日报 / 周报 / 月报。AI 会通读这个周期的记录：正文、标签、
  天气地点、**链接标题**、附件信息（**txt/md/csv 等文本附件的内容也会读进去**，
  打开"视觉能力"后照片也会给多模态模型看；视频只提供文件名和时长，不会整个上传）。
  产出摘要、成就、挑战、经验和建议，并自动画一张思维导图；
  重要结论都带"证据"小链条，点击跳回原始记录。报告可以删除（列表或详情页里点 ×）。
- **报告的周期**：周报按**自然周（周一至周日）**、月报按**自然月**统计。
  如果本周/本月还没过完就点生成，会先问你一句：生成**上周/上月完整报告**，
  还是**本周/本月至今**——同一周期重复生成只会覆盖，不会重复堆积。
- **报告的可靠性**：AI 写报告前必须先按时间顺序列出"原子事实"（每条都对应具体记录），
  只有事实支撑才敢下结论；相邻日期才有因果关系的事才会这样写，空白日不会编造；
  发现入职/换岗/场景切换等环境变化时会分段分析，不跨段拼因果。
  报告详情里可以展开"事实时间线"逐条核对，重要结论都带"证据"小链条跳回原始记录。
- **问小满**：在"记录"页搜索框输入一个问题（如"我上个月踩过哪些坑？"），点"✦ 问小满"，
  AI 会翻遍你的记录回答并附上出处；配了嵌入模型后更懂语义。
  它听得懂时间（"上个月""8 月初""后来怎样了"），查不到会老实说"记录里没找到"，不瞎编；
  开启"视觉能力"后，照片的内容描述也会进入检索。
  每条记录详情页底部还会悄悄出现"相关的回忆"。
- **让小满问我两句**：快速记录卡上的安静小链接——小满会根据你最近的记录温柔追问，
  你随口回答，聊完它自动帮你整理保存成一条记录。不知道写什么的时候试试。
- **心情曲线**：小模型自动给每条记录推断心情（不用你打分），数据页有近 30 天的心情趋势。
- **微信推送**：设置页粘贴 Server酱 SendKey 或 PushPlus token 后，小满会主动找你：
  **每天早上**一封晨报（日期节气、今天天气、昨天你说的"今天要做的事"、一条 N 天前的今天、
  一句引导）；**每晚**一封回顾（昨天的记录、里程碑、待确认的知识提醒）；
  自动周报/月报生成好会**立刻推给你**摘要，AI 圈了高光时刻也会一并报喜。
- **明日接力**：如果你昨天的记录里写了"明天要做什么"，今天页会悄悄提醒你。
- **今日意图**：今天页顶部有一行安静的"今天打算……"，随手写一句，失焦自动保存；
  晚上的回顾推送会把"早上说的"和"今天实际做的"轻轻放在一起（只对照，不评判）。
- **小满发现的规律**：数据页顶部——小满每周一会把你近半年的记录悄悄算一遍，
  发现"某类事出现的日子心情更好""熬夜之后第二天效率低"这类规律（达到统计门槛才说，
  且会注明只是相关不是因果）；每条都可以点"不感兴趣"，它以后就不提这类了。
- **年度故事卡**：报告页顶部的"我的 2026 故事 →"——点开是一屏一卡的滑动故事流：
  超大数字、一句判词、还有小满从你的记录里选出的金句（原话，注明日期）。每周自动更新。
- **随便翻翻**：记录页搜索行最右的 shuffle 小图标，随机打开一条旧记录。
- **时间胶囊**：今天页"✦ 给未来留句话"——写给三个月后的自己，到期那天自动浮出来。
- **高光时刻**：不用你操心——每次生成报告时，AI 会自动把本期最值得纪念的记录
  （第一次做成的事、突破、有意义的瞬间）标上星，聚到成长页的"高光时刻"墙。
- **写成故事**：详情页"导出"里选"写成故事"，AI 把这一天润色成一篇小文章（原记录不动）。
- **长河**：记录页右上"长河 →"，所有记录按月串成一条时间的长河。
- **访问口令**：设置页可给小满上锁（同 Wi-Fi 下防别人打开），Agent 接口不受影响。
- **数据页**：近 30 天 vs 之前 30 天的滚动对比卡（记录数、字数、心情均分、最常标签），
  以及"你写了约等于 N 篇中篇"的小彩蛋。
- **自动报告**：周日晚自动生成上周周报、每月 1 号生成上月月报（设置页可关）。
  月报会对比上月，标出"反复出现的挑战"。
- **小彩蛋**：快速记录框下每天一句引导语（有 AI 时按你最近的记录个性化生成）；
  连续记录 7/21/30 天、总数过 10/50/100 时有小小的庆祝；今天页有节气，
  偶尔还会遇见"N 天前的今天"。
- **知识库**：AI 会从报告里自动提炼"经验、踩坑、案例、SOP、技能"，先进"待确认"，
  你点"入库"才算数 —— 这些就是你以后写教案和书的素材，可以一键导出 Markdown。
  所有条目都能**编辑和删除**（待确认/已入库/已拒绝都可以）。
  同周期**重新生成报告会覆盖旧报告**；知识去重是三道闸：生成时 AI 就能看到已有知识清单
  （含你否决过的，不会再提）、入库前按标题和**语义**判重（同一件事换说法也拦得住）、
  待确认的只更新不新增。你已入库或已拒绝的**绝不会被动**。
- **媒体自动命名**：新上传的附件会由小模型结合记录内容（图片还会看画面）自动起个
  描述性的名字，只改显示名、不动原件；老文件保持不变。点附件上的铅笔图标可以随时改名。
- **成长页**：打开先看到"我的成长轨迹"——AI 通读你最近的记录，总结你已经会了什么、
  做成了什么（里程碑时间线 + 亮点 + 一排小图表：近 12 周趋势、工作生活占比、知识分布），
  首次打开自动生成，之后可点"重新总结"刷新。
  **不用填目标**：点"发现我的方向"，AI 会从你的记录里读出 2-3 个适合你的方向，
  挑一个顺眼的就生成未来路线；记录满 8 周后，还能做"基准 / 积极 / 保守"三种未来 90 天情景推演。
- **圈子**：小满会从记录里自动认识你提到的人、地方和事，建起带出处的小档案。
  你笔记里**明写的事实**（如"8月6日下大雨"）她会直接采信、不再来问；
  推断出来但把握大的，她会自己确认，然后在「小满最近自己拿的主意」折叠区里等你抽查，
  不对就一键撤销；只有真拿不准的才来问你，而且同一条记录的几个疑问会**合并成一张卡片一次问完**，
  还带上她猜的答案。她还会自己认出"老王"和"王师傅"是同一个人（自动合并、可撤销，
  你否定的配对永不再问）；人会变——"离职/搬家"这类变化会**封存旧事实进历史**而不是覆盖。
  跨多天的同类事（如连续几天的喷灌作业）会自动聚成**一条事件档案带时间线**。
  报告、问小满、对话都会参考这些档案——它知道"张工"是谁。
  你有最终审查权：可以确认、改写、合并、或让它"按我的描述重新整理"。
  「关系」页能看到一张以你为中心的关系图：点节点看档案，图例可按人/地/事过滤，
  滚轮缩放、双击空白复位。首次使用点"从全部记录建立档案"，它会把你写过的记录全部翻一遍。
- 某条记录不想被 AI 分析：编辑那条记录，在"更多细节"里勾选"不让 AI 分析这条"。
- 视频**不会**整个发给 AI；图片默认也不发，除非你在设置里打开"视觉能力"。

## 五、数据和备份

- 一切都在程序目录下的 `data` 文件夹：
  - `vault.db`（核心数据库：记录、知识库、报告、成长总结/路线/推演、设置、向量）
  - `media\`（照片、视频、文件等所有附件原件）
  - `thumbs\`（缩略图，可重建）
  - `backups\`（自动备份 zip，未自定义目录时在这里）
- **自动备份**：每 20 小时自动打包一次（数据库一致性快照 + 全部媒体原件），
  可在设置页改成任意目录——**推荐直接指向网盘的同步文件夹**，网盘客户端就会自动上传；
  本地只保留最新 14 份。注意：备份包含 AI Key 等设置项，请勿随手分享。
  每份备份内嵌校验清单并自动自检；设置页可以点「验证最近一次备份」，
  确认它真的完整能恢复。
- `设置 → 数据 → 下载完整备份`：手动打包成 zip。
- **恢复**：关闭小满，把 zip 里的 `vault.db` 和 `media\` 解压覆盖回 `data\`，再启动即可。
  **备份已包含全部设置（含 AI Key）**，换电脑恢复后无需重填；也正因如此，请妥善保管备份文件。
- `设置 → 数据` 还能把任意时间段的记录导出成 Markdown（带附件），方便迁移和写作。

## 六、给其他 AI Agent 用（进阶）

`设置 → Agent` 里有一串 token。你的其他 AI 工具带上它就能读写这个证据库
（请求头 `Authorization: Bearer <token>`）。

**MCP 直接挂载（推荐）**：项目根目录有 `mcp_server.py`，在你的 Agent 平台的 MCP 配置里加：

```json
{
  "command": "<项目目录>\\.venv\\Scripts\\python.exe",
  "args": ["<项目目录>\\mcp_server.py"],
  "env": {
    "XIAOMAN_URL": "http://127.0.0.1:52122",
    "XIAOMAN_TOKEN": "设置页 → Agent 里的 token"
  }
}
```

## 七、关于嵌入模型更换

嵌入模型负责语义搜索（问小满、相关回忆、知识去重）。**更换模型或换不同维度的型号时**：
保存设置的瞬间，旧向量会自动清空（不同模型的向量空间不兼容，混算必错），
后台每 10 分钟自动用新模型重建，也可以点"为历史记录建立语义索引"立刻重建。
全程不用手动干预，重建期间语义功能暂时退回关键词检索，不影响记录。

## 八、常见问题

- **手机打不开**：确认连的是同一 Wi-Fi；电脑防火墙是否放行了 Python；电脑是不是关机/睡眠了。
- **端口被占用**：`start.bat` 里把 `52122` 改成别的数（如 `52130`），访问地址跟着改。
- **视频没有缩略图**：装一个免费的 [FFmpeg](https://ffmpeg.org/download.html) 并加入 PATH 即可，不装也能正常用。
- **想看运行日志**：黑窗口里现在都是中文日志（什么时候保存了记录、AI 补全结果、
  推送成功失败、备份到哪了、报告生成用时等），完整日志在 `data\logs\app.log`，
  记事本打开就能看，超 2MB 自动归档。
- **公司 Wi-Fi 连不上**：有些公司网络禁止设备互访，换家用网络或手机热点即可。

## 九、设计取舍

本实现选择"电脑当主机 + 手机浏览器访问"的架构，而不是原生双端 App：

- 浏览器访问零安装，手机扫码即用，不必安装和维护 App；
- 数据只有一份，天然不存在同步冲突；
- 对个人用户，能双击跑起来、坏了能重装，比架构漂亮更重要。

暂不支持（未来可加）：手机断网时冷启动网页（浏览器安全限制，需 HTTPS 证书体系）、
数据库加密、OCR/视频转写（接入 FFmpeg 和视觉模型后可开）、多人使用。

## 这是什么

小满是一款**本地优先**的个人成长记录器。它把你每天的工作和生活随手记下来，再用 AI 把这些碎片整理成日报、周报、月报，提炼出可复用的经验与 SOP，并慢慢画出一条属于你自己的成长轨迹。

它像一个跑在你电脑上的私人小助手：

- 数据只存在你自己的磁盘上，不经过任何人的服务器；
- 记录不挑格式，正文、照片、视频、文件、网页链接都能往里放；
- AI 负责减负，不负责替你做主。所有结论都带"证据"，能一键跳回原始记录核对。

> 小满者，小得盈满。将满未满，日进一步。

## 设计理念

| 原则 | 含义 |
| --- | --- |
| **本地优先** | 数据库、照片、备份全部在本地 `data/` 目录，不联网也能写。 |
| **轻到没有负担** | 标题、摘要、标签都可以不写。想到什么写什么，AI 帮你补全。 |
| **AI 只做减负** | 帮你整理、归类、总结，但把判断权和终审权留给你。 |
| **证据可追溯** | 报告的每条重要结论都挂着来源记录，不编造、不臆测。 |
| **开放而非封闭** | 提供 MCP 和 REST 接口，你的其他 AI 工具可以直接读写它。 |

## 主要特性

**记录**

- 像发朋友圈一样写字，正文、照片、视频、文件、链接都支持
- 一键插入工作日志模板（工作内容、挑战、解决办法、提升、手记、见识、学习），模板可自定义
- 补写过去的日志，随时修改，删除进回收站（30 天内可恢复）
- 拍照识别手写笔记，多页自动合并成一条记录
- 附件网页内直接预览（文本、PDF、音频、图片、视频）
- 自动预填天气、地点与温度
- 草稿自动保存，切走再回来不丢

**AI 助理**

- 后台自动补标题、摘要、标签，并归类到 12 个类目
- 自动生成日报、周报、月报，附思维导图和事实时间线
- "问小满"：用自然语言翻遍你的记录回答问题，并给出处
- 发现记录之间的隐性关联，比如"周末练车"和"工作里的观光车任务"
- 从报告里提炼经验、踩坑、案例、SOP、技能，进入知识库待你确认
- 心情曲线、规律洞察、年度故事卡、时间胶囊、高光时刻
- 明日接力、今日意图：把"昨天说要做的"和"今天实际做的"轻轻放在一起
- 微信推送：早报、晚回顾、周报月报生成后主动找你

**成长与圈子**

- 成长轨迹：总结你已经会了什么、做成了什么，附趋势图表
- 发现方向：从记录里读出适合你的 2 到 3 个方向，生成未来路线
- 90 天情景推演：基准、积极、保守三种未来
- 圈子：自动认识你提到的人、地方和事，建立带出处的小档案和关系图
- 长河：所有记录按月串成一条时间线

**数据**

- 每 20 小时自动备份，可指向网盘同步目录
- 任意时间段导出为 Markdown（带附件）
- 可设置访问口令，防止同 Wi-Fi 下别人打开
- 一键验证最近一次备份是否完整可恢复

## 快速开始

需要 **Windows** 和 **Python 3.11 以上**。

1. 安装 Python：到 <https://www.python.org/downloads/> 下载，安装时**务必勾选 "Add python.exe to PATH"**。
2. 克隆本项目到自己电脑上的任意目录：

   ```bash
   git clone https://github.com/Liang2248/xiaoman-growth-vault.git
   ```

3. 双击项目里的 `start.bat`。首次运行会自动准备环境（约 1 到 2 分钟），之后浏览器会自动打开 <http://localhost:52122>。

想用 AI 功能，打开网页里的**设置**页，填入任意兼容 OpenAI 接口的服务商（DeepSeek、通义千问、OpenAI 等）的 Base URL、模型名和 Key 即可。Key 只保存在本机。

## 手机怎么用

1. 手机和电脑连**同一个 Wi-Fi**，电脑上运行 `start.bat`。
2. **先在电脑上设置访问口令**：打开电脑网页的**设置**页，设置一个访问口令。出于安全，未设口令时小满只允许本机访问，手机等设备会被挡在外面。
3. 设置页顶部的“手机连接”卡片里有二维码，手机扫码（或用浏览器打开卡片里的地址），输入口令即可访问。
4. 可以把网页“添加到主屏幕”，用起来就像 App，拍照记录最方便。
5. 断网时也能先记，回到 Wi-Fi 会自动同步。

## 给 AI Agent 用

小满内置完整的外部接口，你的其他 AI 工具可以直接读写它。

**方式一：MCP 挂载（推荐）**

项目根目录有 `mcp_server.py`，在你的 Agent 平台 MCP 配置里加入（把路径换成你自己的实际路径）：

```json
{
  "command": "<项目路径>\\.venv\\Scripts\\python.exe",
  "args": ["<项目路径>\\mcp_server.py"],
  "env": {
    "XIAOMAN_URL": "http://127.0.0.1:52122",
    "XIAOMAN_TOKEN": "<设置页 → Agent 里的 token>"
  }
}
```

**方式二：REST API**

所有 `/api/agent/` 请求带上请求头 `Authorization: Bearer <token>` 即可。用 `GET /api/agent/capabilities` 可以拿到全部端点的中文说明，用免鉴权的 `GET /api/healthz` 探活。

> ⚠️ Agent token 具备**读、写、删除**记录的权限。请只把它交给你信任的工具，不要写进公开的配置或代码里。删除操作虽可在回收站恢复，仍请谨慎授权。

## 数据与隐私

- 所有数据都在项目目录下的 `data/` 文件夹：`vault.db`（数据库）、`media/`（附件原件）、`thumbs/`、`backups/`。
- 小满**不会**把数据上传到任何第三方服务器；只有你主动配置了 AI 服务商，记录才会在你点下相关功能时发送给该服务商。
- 标记为"不让 AI 分析"的记录，不补全、不向量化、不进报告。
- 备份包含 AI Key 等设置项，**请勿随手分享备份文件**。
- **默认只认本机**：未设置访问口令前，小满只接受来自本机的访问，同一 Wi-Fi 下的其他设备会看到一道引导页；设置口令后，手机等设备凭口令访问。既方便手机使用，也不会在局域网里“裸奔”。
- 本项目已在 `.gitignore` 中排除整个 `data/` 目录，源码仓库不会包含任何个人数据。

## 技术栈

- 后端：Python 3.11+、FastAPI、Uvicorn

- 接口：MCP Server + REST Agent API

## 常见问题

**手机打不开？** 确认连的是同一个 Wi-Fi；检查电脑防火墙是否放行了 Python；确认电脑没有关机或睡眠。

**端口被占用？** 修改 `start.bat` 里的 `52122` 为其他端口，访问地址跟着改。

**视频没有缩略图？** 安装 [FFmpeg](https://ffmpeg.org/download.html) 并加入 PATH，不装也能正常使用。

**想换 AI 服务商？** 设置页支持同时保存多家，分别给大模型、小模型、嵌入模型选用。
